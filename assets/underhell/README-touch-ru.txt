Underhell — дополнительные экранные кнопки
=========================================

ОСНОВНОЙ СПОСОБ: ОБНОВИТЬ APK ЛАУНЧЕРА

Установите новый APK underhell и начните/продолжите игру. Все иконки уже внутри
лаунчера. Кнопки включаются автоматически при первом входе в карту после обновления,
в том числе поверх старого сенсорного профиля с отключённым HUD. Ничего копировать,
выполнять exec или дописывать в параметры запуска не требуется.
Положение ваших существующих кнопок сохраняется; после первого включения можно
редактировать/скрывать кнопки — выбор будет учитываться при последующих запусках.

Ниже оставлен запасной ручной способ ТОЛЬКО для старого APK без обновления.

ЗАПАСНАЯ РУЧНАЯ УСТАНОВКА НА СТАРЫЙ APK

1. Распакуйте каталог underhell из архива в корень ресурсов Source Engine,
   где уже находятся underhell и hl2. Объедините папки, не удаляя свои файлы.
   Правильный путь, например:
   underhell/materials/vgui/touch/underhell/inventory.vtf
   underhell/cfg/underhell_touch.cfg
   Везде используется точное lowercase underhell. gameinfo.txt в пак не входит.

2. В консоли игры выполните:
   exec underhell_touch.cfg

   Либо добавьте в параметры запуска лаунчера:
   +exec underhell_touch.cfg

3. Начните/продолжите локальную игру: в главном меню сенсорный HUD штатно скрыт.
   Чтобы сохранить расположение в текущий сенсорный профиль:
   touch_writeconfig

Повторный exec сбрасывает ТОЛЬКО 14 кнопок с именами uh_* из этого пака.
Существующие кнопки движения, атаки, прыжка и ваши остальные бинды не удаляются.
Расположение можно поправить в штатном редакторе touch_enableedit.
Текстуры — настоящие VTF 7.2, 64x64, RGBA8888 с прозрачностью, без mipmaps.

КНОПКИ / КОМАНДЫ

Рюкзак        cl_inventoryToggle       Инвентарь
Прицел        ironsight_toggle         Прицеливание
Очки          NightVision_Toggle       ПНВ
Маска         GasMask_Toggle           Противогаз
Луч           laser_toggle             Лазер (поддерживаемое оружие)
Глушитель     silencer_toggle          Глушитель (поддерживаемое оружие)
Три патрона   firemode_toggle          Режим стрельбы
Планшет       DispObj                  Показать задачу
Ботинок       uh_jake_kick             Пинок
Граната       Throw_Nade               Бросить гранату
Часы          impulse 110              Замедление времени
Стрелка вниз  DropWeapon               Выбросить оружие
Рация         GiveSign                 Сигнал для карты
Две стрелки   SkipScene                Пропустить сцену, если карта поддерживает

Кнопки не выдают снаряжение и не обходят запреты карты. Нужны соответствующие
предметы/оружие; сигнал и пропуск сцены работают только там, где есть обработчик.

ОПЦИОНАЛЬНО: МЕНЬШЕ НАГРУЗКИ НА TOGL ES

Сначала сохраните копию underhell/cfg/config.cfg. Затем можно выполнить:
   exec underhell_android_fast.cfg

Профиль отключает тени фонаря, render-to-texture тени, принудительные дорогие
отражения воды и motion blur. Луч фонаря, ПНВ и игровые механики не отключаются.
Это компромисс качества и нагрузки, а не исправление/замена TOGL ES и не гарантия
определённого FPS. Значения могут сохраниться движком в config.cfg; для возврата
используйте свою копию конфигурации или прежние настройки графики.

В ОБНОВЛЁННОМ НАТИВНОМ КЛИЕНТЕ (НЕ В СТАРОМ APK)

Кнопки добавляются автоматически, без затирания имеющегося touch.cfg. Иконки
упаковываются в extras_dir.vpk; в библиотеке есть резервная копия тех же пикселей.
Есть 15-я кнопка с молнией: обратимое переключение облегчённой графики в текущей
сессии. Команды нового клиента:
   uh_touch_buttons 0 / 1   Скрыть / показать дополнительные кнопки
   uh_touch_reset          Сбросить только расположение кнопок Underhell
   uh_android_fast 1 / 0    Облегчённая графика / вернуть прежние значения сессии

Для возврата графики выключайте режим до сохранения конфигурации/выхода.
Копирование этого пака НЕ обновляет DLL и не добавляет новые нативные команды
в уже установленный APK. Исправления обработки касаний и атласа требуют сборки
обновлённого клиента; пак с 14 кнопками работает через существующие команды.
